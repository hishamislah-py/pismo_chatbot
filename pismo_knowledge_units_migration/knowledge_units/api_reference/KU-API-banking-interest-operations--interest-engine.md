### `POST /v1/interest/balance` — Create balance

- **operationId:** `post-v1-interest-balance`
- **Specification:** `api-specs/Banking_-_Interest_operations.yaml` (Banking - Interest operations)
- **Server base URL(s):** `https://sandbox.pismolabs.io/interest-engine`
- **Tags:** `Interest engine`
- **Deprecated in specification:** no
- **Security requirement:** `BearerAuth`

**Description (from the specification):**

> Register a balance for an interest-bearing account using a previously configured interest plan to determine applicable interest rates.
>
> This endpoint generates the Interest balance succeeded event when the balance is created successfully.
>
> The event payload includes: `program_id`, `balance_id`, `account_id`, `interest_plan_id`, `balance`, `start_cycle_date`, `value_date`, and `maturity_date`. The optional field `external_account_id` is included in the event only when present in the request. The division fields `division_id` and `division_code` are included in the event only when a non-default division is provided. They are omitted when `division_id` is `DEFAULT_DIVISION` or the value is null.
>
> The optional field `external_account_id` is only returned in the response when present in the request.
